# TESSAVRIK — ტესავრიკ · გამოშვებები

აქ მხოლოდ TESSAVRIK-ის მზა პროგრამაა Windows-ისთვის. წყარო კოდი აქ არ არის.

## გადმოწერა

1. გახსენი **[Releases](../../releases/latest)** და გადმოწერე `TESSAVRIK-<ვერსია>-win64.zip`.
2. ამოაარქივე სასურველ საქაღალდეში (მაგ. `C:\TESSAVRIK`). Python ან სხვა პროგრამის დაყენება საჭირო არ არის.
3. გაუშვი `TESSAVRIK\TESSAVRIK.exe`.

> Windows შეიძლება გაფრთხილებას აჩვენებდეს („Windows protected your PC“), რადგან პროგრამას ჯერ ციფრული
> ხელმოწერა არ აქვს. დააჭირე **More info → Run anyway**.

## ლიცენზია

პროგრამა გაიხსნება მხოლოდ იმ კომპიუტერზე, რომელზეც ლიცენზიაა გაცემული.

1. პირველ გაშვებაზე ფანჯარაში გამოჩნდება **კომპიუტერის კოდი** (`XXXX-XXXX-XXXX-XXXX`). დააჭირე „კოდის კოპირება“.
2. გაუგზავნე კოდი და შენი სახელი TESSAVRIK-ის ავტორს.
3. მიღებული `.tsl` ფაილი ჩატვირთე ღილაკით „ლიცენზიის ფაილის ჩატვირთვა…“.

ლიცენზიის ვადის ამოწურვამდე 5 დღით ადრე პროგრამა გაფრთხილებს. მოგვიანებით ლიცენზიის ნახვა ან ახლის ჩატვირთვა:
მენიუ **დახმარება → ლიცენზია…**.
